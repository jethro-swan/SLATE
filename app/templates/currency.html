Notes

  • Note 1: It is not yet entirely obvious how this should be implemented, but the download link must restrict access to the steward downloading the file and should be time-limited.

  • Note 2: The accounts must have been created already and (obviously) must all be in this currency. Any which are not will be displayed as errors.

  • Note 3: The policies to be followed remain to be agreed, but a possible approach would be to provide a form to add or recommend a new steward for this currency. This is because all current stewards should probably have an opportunity to veto or otherwise influence any decision to appoint a new steward. The temporary solution implemented here allows only for the immediate unilateral adding of a new steward.
    Policy to be discussed.

  • Note 4: The policies to be followed remain to be agreed, but a possible approach would be to provide a form to propose removal of an existing steward of this currency. All current stewards should probably have an opportunity to veto or otherwise influence any decision to remove an existing steward, and this includes the steward whose removal is being proposed. It must also be possible for a steward to signal the intention to resign from this role, but at least one steward must always exist if the currency is to remain in use. As a last resort, the sole remaining steward may (in effect) close the currency but in that case the owners of the accounts in this currency must be provided with a way to transfer their account records to another (metrically equivalent) currency (whether or not they already have accounts in that).
    These are policies to be discussed.
