Here you can import a CSV file to create a set of payments a CSV file, each row of which specifies:
  • a currency - created if it does not exist already
  • a payer account-holder
  • a payee account-holder
  • a payment amount
  • an annotation
where
  • Any of the entities specified (account-holder or currency) will be created within the uploading identity's private namespace if they do not exist already, as will any new namespaces required to complete the parent.
  • Any new currency or namespaces created will be assigned the uploading identity as its initial steward.
  • Any currency|account-holder pairing (identifying an account) will be created if it does not exist already. (NB, any currency specified may be used if the uploading identity is authorized to do so. It is only the newly-created currencies) that are restricted to that identity's private namespaces.
