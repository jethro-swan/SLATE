You will not be able to register (i.e. to create your primary identity) unless both an initial parent namespace and an initial currency are specified.

Upon registration, a namespace will be created for you with the specified parent namespace and an intial account (in the specified currency) will be created for you within your own namespace. That account will be given the same name as the currency.

For example, if the parent namespace is someneighbourhood.sometown.somewhere, the username you have chosen is fred and the initial currency is local£.possibly.somewhere.else, then

  • your namespace will be fred.someneighbourhood.sometown.somewhere
  • your initial account will be local£.fred.someneighbourhood.sometown.somewhere

If you were to specify your username as fred.flintstone then the intermediate namespace flintstone would be created for you, assigning you its initial stewardship. This might be useful, for example, when creating a namespace for a town, a neighbourhood, an organization or a family. It would then be your responsibility to assign additional stewards to these new namespaces.

You will not be able to use any name that already exists within a namespace.
