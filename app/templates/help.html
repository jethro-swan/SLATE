{% elif help_page == "create_namespace" %}

Use this form to create a new currency.

  • The parent namespace must exist already.
  • The parent namespace must be one in which you are authorized to create new entities. This will be the default behaviour in most public namespaces but will generally not be allowed in most private namespaces.
  • The name (the part preceding the parent namespace string) must not contain any name-separator characters (usually "." when using the Latin alphabet).
  • The login identity (primid) creating this currency will be its initial steward.

{% elif help_page == "create_currency" %}

Use this form to create a new currency.

  • The parent namespace must exist already.
  • The parent namespace must be one in which you are authorized to create new entities. This will be the default behaviour in most public namespaces but will generally not be allowed in most private namespaces.
  • The name (the part preceding the parent namespace string) must not contain any name-separator characters (usually "." when using the Latin alphabet).
  • The login identity (primid) creating this namespace will be its initial steward.

{% elif help_page == "create_pairing" %}

Use this form to pair a currency with a, account-holder identity (ahid) creating a new account.

  • The ahid will be created automatically if it does not exist already.
  • If the currency does not exist already, nothing will happen.
